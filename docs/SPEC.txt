Это модуль для платформы совместного обучения.
Платформа совместного обучения представляет собой что-то похожее на Miro.
Смысл модуля в предоставлении простого API для расширения платформы, 
который позволяет добавить на платформу виджет для исполнения SQL-кода.

Зачем нужен виджет: интерактивное обучение на онлайн-платформе, смысл 
который в возможности онлайн-взаимодействия преподавателя и студента 
по предмету SQL базы данных.
Смысл в следующем: преподаватель создает карточку с заданием, где
указывает формулировку задачи, сколько баллов за решение, 
а также может добавить список подсказок, каждый из которых понижает итоговые балл; 
после чего преподаватель назначает студента, который должен решить задачу.
После того, как преподаватель заполнил карточку, студент приступает к решению задачи, 
нажимая на карточку. Здесь он может писать SQL-запрос, после чего отправлять его для
проверки решения. Если у него возникают какие-то трудности, то он может выделить строки
запроса и попросить преподавателя помочь ему, нажав соответствующую кнопку. 
Аналогичным образом, при проверке работы, преподаватель может выделять неправильные строки.

Детали реализации.
Модуль проектировался как можно более легкий во всех смыслах: количестве
и сложности реализации зависимостей, минималитичном API (чем меньше -- тем 
сложнее сломать и проще интегрировать).
Модуль сделан на React и TypeScript (так как он используется и в целевой платформе), 
весь модуль упаковывается в npm-пакет для стандартной последующей интеграции.
В качестве стилей используется крошечная библиотека компонентов, позволяющая организовать
единый интерфейс на всех платформах.
